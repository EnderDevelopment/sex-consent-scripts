# Interactive Story Game

Script & Sex is an open source interactive story game built with HTML, CSS, and JavaScript. Choose actions to explore a branching script about a mysterious harbor, follow your choices through the story, and discover five different endings.

## Install

1. Download or clone the project files.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a modern web browser.

## Use

1. Read the current scene.
2. Select a button to choose an action and advance the story.
3. Follow the path history to review your choices.
4. Select “Restart story from the beginning” to start over and explore another route.
